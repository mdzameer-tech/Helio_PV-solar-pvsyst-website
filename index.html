ESP32 Gateway Configuration

Ensure your ESP32 and this computer are connected to the same Wi-Fi network (or mobile hotspot).

Paste into esp32_gateway.ino (line 34): 
const char *BACKEND_URL = "http://localhost:3000/api/data";

Quick Hardware Checklist:

• Master Node: DFRobot Beetle ESP32-C6 receiving over nRF24L01+ Multiceiver (4 pipes).

• Micro-Nodes: CH32V003 transmitting every ~2s (P1, P2, P3, and String Node).

• Auto-ACK & Post: ESP32 auto-ACKs received packets and sends HTTP POST to /api/data.
